# Flash-Next Selected-QSA Semantic Protocol

Status: frozen before evaluator code or model acquisition.

## Question

Does experimental selected-range packed QSA preserve quant-native semantic
quality closely enough to clear its default-off hold?

The bounded decision requires:

- pooled teacher-forced
  `mean_nll(selected) - mean_nll(safe) <= ln(1.01)` over two held-out natural
  contexts; and
- selected known-answer output with
  `code == "amber-lattice-2049"` and `record == "K-17"`.

No BF16 or llama.cpp row is required. Default-safe scalar continuation is a
paired control, not numerical truth.

## Frozen Inputs

`fixtures.json` binds the released model, tokenizer, complete token arrays, and
source provenance. The natural fixtures are the first 2,211 released-tokenizer
IDs from two local macOS manual pages that are external to this repository:

- OpenSSH `ssh(1)`;
- Z shell `zsh(1)`.

Neither source, token slice, nor safe/selected output was used by the removed
multi-hour selected-quality harness. No model output from these fixtures was
inspected before this protocol. The checked-in U32LE arrays, not mutable system
paths, are acquisition authority.

For each natural fixture:

- prompt range: `[0, 2179)`;
- target range: `[2179, 2211)`;
- target count: 32;
- tokenizer special-token insertion: disabled.

The known-answer prompt is a frozen 2,578-token rendered chat fixture with one
superseded K-17 code, one ratified K-17 code, and one same-code K-71 distractor.
Its complete token array is checked in beside the text.

## Runtime

- Load the three-shard UD-Q3_K_XL release once from the internal SSD.
- Reject every `QWEN*` environment variable except the model-path variable
  before model load; use only committed defaults.
- Allocate one runner with forward limit 2,642. The ratio-aligned physical QSA
  capacity must be 2,644, packed capacity 2,048, and selected scratch capable.
- Use the test-scoped selected-QSA override; do not set the public environment
  switch.
- Before every arm, call `reset()`, assert position zero, zero every enumerated
  persistent-state tensor, and assert logits are unavailable.
- Run exactly this order without retries:
  1. ssh safe;
  2. ssh selected;
  3. zsh safe;
  4. zsh selected;
  5. known-answer safe;
  6. known-answer selected.

One temporary ignored test in `qwen4exp_runtime.rs` may perform the acquisition.
Do not enable decision captures, composition traces, dispatch census, profiling,
or broad test suites.

## Natural NLL

For each arm, prefill the 2,179-token prompt. The returned full-vocabulary row
predicts target token 2,179. For each of the 32 targets in ascending order:

1. require exactly 248,320 finite F32 logits;
2. compute max-subtracted F64 logsumexp in ascending token-ID order;
3. record `nll = logsumexp - target_logit`;
4. feed that target exactly once, including the final target.

The terminal row after target 32 is unscored. Assert final committed length
2,211. Preserve all per-token NLL values.

Calculate exactly:

`pooled_delta = (sum(selected_ssh,zsh) - sum(safe_ssh,zsh)) / 64`.

The natural gate is
`pooled_delta <= 0.009950330853168092`. Report each context delta, but add no
per-context, top-1, maximum-token, confidence, or bootstrap gate.

## Known Answer

Generate greedily from prompt logits for at most 64 tokens, choosing the lowest
token ID on ties. Stop on released stop token 248046; do not decode or feed the
stop token. Decode and feed every other generated token, including token 64.

From generated bytes only:

1. locate the first exact `FINAL_JSON:` marker;
2. skip JSON whitespace;
3. parse the first JSON value after the marker;
4. require an object with string-valued `code` and `record` fields.

Leading reasoning and trailing generated material are allowed. Safe output must
parse to validate the fixture, but its field values are descriptive. Selected
output must parse within the cap and satisfy both expected field predicates.

## Disposition

- Natural gate and both selected predicates pass: `SEMANTIC_GO`.
- Safe retrieval does not parse: `INVALID_FIXTURE / NO_DECISION`.
- Hash, tokenizer, model, capacity, reset, or safe runtime failure:
  `INVALID_ACQUISITION / NO_DECISION`.
- Valid safe arm followed by selected runtime failure, nonfinite logits, parse
  failure, predicate failure, or pooled NLL over gate: `SEMANTIC_FAIL`.

No retries or output-informed fixture changes are allowed. Any protocol repair
requires a new committed packet. After acquisition, preserve results and remove
the temporary evaluator from the final tree.
