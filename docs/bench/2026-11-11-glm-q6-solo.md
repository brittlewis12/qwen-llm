# GLM Q6 solo-decode band: per-shape census and split-K fusion, 2026-11-11

M5 Ultra, GLM-5.3-Flash UD-IQ3_XXS, `--profile iter`, thermal 0 for every
retained perf packet. Branch `perf/glm-q6-solo`, base main `f03637fa2`.
B=1 uses the serial GPU token loop (`Glm5NextSession::forward`), one command
buffer and one compute encoder per token: all 1,060 dispatches are in a
serial chain, and the Q6 family hold is the authoritative exposure.

## Per-shape census

`glm_solo_bounds ... gridholds` holds one Q6 dispatch class by kernel, grid
width and slot-1 weight bytes. Reference mean 18.456 ms/token at thermal 1
(the shared host was busy); savings are relative and flagged.

| Shape (K x N) | Role | Calls | Hold ms | Profile ms | Effective GB/s |
| --- | --- | ---: | ---: | ---: | ---: |
| 4096x8192 x3 | KDA q/k/v (`_x3`) | 34 | **3.157** | 3.459 | 812-889 |
| 8192x4096 | KDA output | 34 | **1.363** | 1.346 | 686-696 |
| 16384x4096 | MLA output | 10 | 0.704 | 0.704 | 782 |
| 4096x1536 | MLA q_a | 10 | 0.263 | 0.332 | 155-196 |
| 4096x2048 x2 | shared gate+up (fused) | 41 | **1.175** | 1.267 | 446-480 |
| 2048x4096 | shared down | 41 | 0.535 | 2.574* | 529 |
| 4096x12288 | dense gate+up | 6 | **0.609** | 0.699 | 355-407 |
| 12288x4096 | dense down | 3 | 0.228 | 0.203 | 611 |
| 4096x154880 | head | 1 | 0.745 | 0.485 | 698-1,073 |

\* The sampled per-dispatch profile serializes each kernel into its own
encoder; a start can precede the previous dispatch's end, so short dependent
kernels (shared down, q_a) are inflated. The isolated serial probe and the
hold packet agree that shared down is ~13 us/call, not ~63.

The Q6 profile sum is 11.07 ms versus the 7.02 ms family hold: roughly 4 ms
of per-dispatch service is hidden by overlap or is sampling overhead. The
band that is both below streaming and exposed is shared gate+up (1.18 ms),
dense gate+up (0.61), shared down (0.54), and q_a (0.26); KDA/MLA output and
the head are at 60-97% of the 1.106 TB/s reference.

## Candidates and prices

`glm_q6_probe` times each real shape over a rotating set above the M5 shared
cache, one dispatch per command, so successive calls cannot overlap.

| Mapping | Isolated vs incumbent | In-schedule result |
| --- | ---: | --- |
| Research vector (V4.1 work-split analogue) | 0.94-1.63x by shape | Neutral; loses on q_a/shared |
| Split-K single (one threadgroup/row, K split) | 1.04-1.70x vs r1 | Neutral alone; part of the shipped set |
| Pair SwiGLU split-K (same-input gate/up) | 1.47x vs fused, 2.15x vs two r1 | Dense **1.96x**, shared slower |
| Triple split-K (KDA q/k/v) | 1.69x vs r1, ~1.05x vs `_x3` | Small positive in the full set |
| Split-K head | 1.54x vs two-row | Small positive |
| Split-K q_a | 1.04x | Small positive in the full set |

The full candidate set (hex mask `3f`: split-K outputs, shared/dense pair
SwiGLU, KDA triple, head, q_a) is the shipped default. Shared-down split-K
(bit 6) is research-only: its isolated mapping is a slight loss.

## Whole-path B=1 counterfactual

`glm_solo_bounds ... research 3f 3`, 32 steps/arm, ABBA, six retained arms
per config. All six candidate arms beat all six controls at both depths.

| Depth | Control ms/token | Candidate ms/token | Saving | Thermal |
| ---: | ---: | ---: | ---: | --- |
| 32K | 17.0072 | 16.5000 | **0.5072** | 0 |
| 48K | 17.1179 | 16.6062 | **0.5117** | 0 |

Mask prices at 32K, thermal 0: `1f` 0.4966, `3f` 0.5183, `5f` 0.5148. The
difference between masks is within ~0.03 ms; `3f` is the best repeated
thermal-0 set and is shipped.

## Exactness

Same-process teacher-forced full-vocabulary logits, 32 targets, 32K:
mean signed dNLL **-9.39e-9**, mean |dNLL| **1.19e-8**, max |dNLL| 1.11e-7,
mean KL **1.32e-11**, max KL 2.42e-10, argmax 32/32, finite 32/32. This is
F32 reassociation only, non-inferior to the incumbent.

## Shipped

Default-on `QWEN_GLM53_Q6_SOLO` (`=0` restores the incumbent Q6 matvec and
fused shared SwiGLU). Only the serial B=1 path changes: the packed batched
path (`packed.rs`) keeps its own mat-mat/tile selection, so B=3 is unchanged.
Product kernels live in `kernels/mat_vec_q6_k_solo.metal`; the research mask
`QWEN_GLM53_Q6_RESEARCH` and `glm_solo_bounds {profile,gridholds,research,quality}`
stay bench-only.
