# V4.1 header fold: qualified 1..=2048-row band

Status: landed. Warm-append header folding now covers the full `1..=2048`
suffix band, so sub-512 appends fold and the 2048-row ceiling is unchanged.
`QWEN_SERVE_V41_FUSE_HEADER=0` restores the separate header call.

## Quality

Reused the frozen 2026-11-07 probe: 48K and 80K code/prose cohorts, 128
teacher-forced targets per cell, full finite vocabulary. Each cell compares
the folded append against the separate two-token header call. The gate is
`|dNLL| <= 0.005` and mean KL `<= 0.01`.

| rows | 48K code | 48K prose | 80K code | 80K prose |
| ---: | ---: | ---: | ---: | ---: |
| 16 | 0.0 | 0.0 | 0.0 | 0.0 |
| 150 | -0.00071 | -0.00297 | -0.00069 | +0.00450 |
| 427 | -0.00283 | +0.00241 | -0.00020 | -0.00192 |
| 2260 | +0.00026 | **+0.00845 FAIL** | - | - |

Max mean KL is 1.84e-3, under the KL gate. The only failure is 2260 prose
dNLL, so `2049..=4096` stays on the separate header call and the cap is 2048.
